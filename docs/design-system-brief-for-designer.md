# מדריך עיצוב למעצב גרפי — מערכת CRM «עזרה ורפואה»

מסמך זה מתאר את שפת העיצוב הקיימת באפליקציה (נייד + מחשב), הספריות והסטנדרטים — כדי לשכפל את אותה שפה באפליקציה חדשה.  
**אין צורך בשינוי קוד במערכת הקיימת; זה מסמך ייחוס בלבד.**

---

## 1. תקציר מותג ואווירה

| נושא | הגדרה |
|------|--------|
| כיוון שפה | **עברית RTL** מלא (`dir="rtl"`, `lang="he"`) |
| מצב תצוגה | **Light mode בלבד** (אין Dark כברירת מחדל בשימוש) |
| אופי | CRM תפעולי לצוות בשטח — נקי, מקצועי, כחול רגוע, קריא בנייד |
| צפיפות | בינונית־אוורירית: כרטיסים מעוגלים, ריווח נוח לאצבע |
| תחושה | אפליקציית מובייל־קודם עם שכבת דסקטופ (סיידבר) |

**צבע מותג / Theme (דפדפן):** כחול `#2563eb` (themeColor).  
**Primary בקוד:** גוון כחול־סגול־רגוע (OKLCH hue ~250) — «כחול CRM» ולא סגול־אופנתי.

## 2. ספריות וטכנולוגיות UI (חובה לשכפול)

| תפקיד | ספרייה / כלי | הערות למעצב |
|--------|---------------|-------------|
| עיצוב רכיבים | **shadcn/ui** (סגנון **base-nova**) | קומפוננטות מוכנות: כפתור, דיאלוג, קלט וכו׳ |
| פרימיטיבים אינטראקטיביים | **@base-ui/react** | בסיס ל־Dialog / Sheet / Button / Checkbox וכו׳ |
| עיצוב utility | **Tailwind CSS v4** | כיתות כמו `rounded-2xl`, `bg-primary/10` |
| אייקונים | **lucide-react** | קווי מתאר (outline), לא filled כברירת מחדל |
| טוסטים / התראות | **sonner** | למעלה במרכז, עם צבעים עשירים (`richColors`) |
| וריאציות כפתור | **class-variance-authority (cva)** | variants: default / outline / secondary / ghost / destructive |
| אנימציות קלות | **tw-animate-css** | fade / zoom בפתיחת מודאלים |
| גופן | **Google Font: Assistant** | subsets: Hebrew + Latin |

**ספריית אייקונים:** Lucide בלבד (לא Font Awesome / Material כסטנדרט).  
עובי קו טיפוסי: `strokeWidth` ~1.8 רגיל, ~2.2–2.4 במצב פעיל.  
גודל נפוץ: `16px` (size-4) בתוך כפתורים, `20–24px` בניווט, `28px` בגריד «עוד».

## 4. פלטת צבעים (Design Tokens)

המערכת עובדת עם **CSS Variables** (לא צבעים קשיחים בכל מקום).  
תמצית ל־Figma / Brand:

| Token | תפקיד | תיאור ויזואלי |
|-------|--------|----------------|
| `background` | רקע אפליקציה | אפור־כחלחל בהיר מאוד |
| `foreground` | טקסט ראשי | כמעט־שחור כחלחל |
| `card` / `popover` | משטחי כרטיס / חלונות | לבן נקי |
| `primary` | פעולות ראשיות, לינקים פעילים | כחול מותג |
| `primary-foreground` | טקסט על primary | לבן |
| `secondary` | רקעים משניים / chips | אפור־כחלחל בהיר |
| `muted` / `muted-foreground` | רקע עדין / טקסט משני | אפור |
| `accent` | הדגשות עדינות | כחלחל בהיר |
| `border` / `input` | מסגרות | אפור בהיר |
| `ring` | Focus ring | כחול primary |
| `destructive` | מחיקה / שגיאה | אדום |
| `success` | הצלחה | ירוק |
| `warning` | אזהרה | כתום־ענבר |
| Badges מיוחדים | למשל «ניסיוני» | רקע `amber-100`, טקסט `amber-900` |

**שקיפויות נפוצות:**  
`primary/10` לרקע פעיל בניווט, `destructive/10` לאזהרות, `secondary/40` לכרטיסי תפריט.

## 5. רדיוסים, צללים, גבולות

| Token / שימוש | ערך / התנהגות |
|---------------|----------------|
| `--radius` בסיס | **0.75rem** (12px) |
| כפתורים סטנדרט | `rounded-lg` (~8–10px) |
| כרטיסי תוכן / רשימות | **`rounded-2xl`** (בערך 16–18px) — זה ה־signature של המערכת |
| דיאלוגים | לעיתים `rounded-xl` / `rounded-2xl` |
| Sheet תחתון (נייד) | **`rounded-t-3xl`** — פינות עליונות מעוגלות מאוד |
| צ׳יפים / badges עגולים | `rounded-full` |
| צללים | עדינים מאוד (`shadow-sm` / `shadow-lg` במודאלים); לא multi-layer glow |
| גבולות | `1px` בצבע `border`; מודאלים עם `ring-1 ring-foreground/10` |

## 6. רכיבי UI סטנדרטיים (איך הם «נראים»)

### 6.1 כפתורים
- **Primary:** מילוי כחול, טקסט לבן.  
- **Outline:** מסגרת + רקע card/background.  
- **Secondary / Ghost:** שקט יותר.  
- **Destructive:** רקע אדום שקוף + טקסט אדום (לא בהכרח מלא אדום).  
- גובה טיפוסי: ~32–36px; בכפתורי פעולה גדולים בטפסים: `h-11` / `py-6` עם `rounded-xl` / `rounded-2xl`.  
- אייקון + טקסט עם מרווח קטן; אייקונים ב־Lucide.

### 6.2 שדות קלט (Input / Textarea / Select)
- גובה ~32px (`h-8`) בדסקטופ; בנייד לעיתים גבוה יותר.  
- `rounded-lg` / בטפסים מודגשים `rounded-xl`.  
- Focus: מסגרת ring כחולה (`ring-3 ring-ring/50`).  
- Placeholder בצבע muted.

### 6.3 כרטיסים ורשימות
- כרטיס: רקע לבן (`card`), מסגרת `border`, פינות `rounded-2xl`, ריפוד פנימי ~12–16px.  
- לחיצה בנייד: `active:scale-[0.99]` או `active:scale-95` — משוב מישוש קל.  
- מצבים ריקים: מסגרת מקווקוות (`border-dashed`) + טקסט ממורכז muted.

### 6.4 כותרת עמוד (Page Header)
- דביקה למעלה (`sticky`), רקע `card/95` + **backdrop blur**.  
- קו תחתון דק.  
- כותרת + אופציונלי subtitle + כפתור פעולה בצד (ב־RTL: שמאל ויזואלית).

### 6.5 דיאלוגים / פופאפים (Dialog)
- מרכז מסך, רוחב מקסימלי בנייד: כמעט מלא עם שוליים (`max-w-[calc(100%-2rem)]`).  
- בדסקטופ: בדרך כלל `sm:max-w-md` עד `max-w-lg`.  
- רקע כהה שקוף מעל המסך: `bg-black/10` + **blur קל**.  
- אנימציה: fade + zoom-in קטן בפתיחה.  
- כותרת מיושרת לימין; כפתור X לפינה (סוף שורה ב־RTL).  
- Footer: לרוב שני כפתורים במלוא הרוחב בנייד (`flex-1`), בשורה אחת בדסקטופ.  
- דיאלוג מחיקה: אזהרה בתיבה אדומה־בהירה מעוגלת; כפתור אישור destructive.

### 6.6 Sheet (מגירה / Bottom sheet)
- בנייד לתפריט «עוד»: נפתח **מלמטה**, פינות עליונות `rounded-t-3xl`.  
- תוכן בגריד 3 עמודות של קיצורי דרך מרובעים־מעוגלים (`rounded-2xl`).

### 6.7 Toast (Sonner)
- מיקום: **top-center**.  
- אייקוני Lucide להצלחה / שגיאה / אזהרה / מידע.  
- צבעים עשירים (`richColors`).

### 6.8 Checkbox / Switch / Tabs / Badge
- Checkbox קטן מרובע־מעוגל, checked = primary.  
- Badge / סטטוס: pill או מלבן מעוגל קטן; צבעים סמנטיים (primary/10, amber, violet וכו׳ לפי הקשר).

## 7. ניווט ופריסה — נייד מול מחשב

### 7.1 נייד (ברירת מחדל, עד breakpoint `md`)
- **רוחב תוכן מרבי:** ~`max-w-md` (כמו «מסגרת טלפון» ממורכזת).  
- **Bottom navigation** קבועה בתחתית (4 טאבים + «עוד»):  
  דשבורד · לידים · הדרכות · מודרכים · עוד.  
- רקע תפריט תחתון: `card/95` + blur; התחשבות ב־safe-area (`pb-[env(safe-area-inset-bottom)]`).  
- תוכן עם `padding-bottom` גדול כדי שלא יוסתר מאחורי התפריט.  
- «עוד» → Bottom Sheet עם רשת קיצורים.  
- אין סיידבר.

### 7.2 מחשב (`md` ומעלה)
- **סיידבר קבוע** בצד ה־start של RTL (= ימין במסך), רוחב ~256px (`w-64`).  
- רקע card, גבול פנימי, ניווט אנכי מלא (כל המסכים כולל פעולות מהירות והגדרות).  
- פריט פעיל: רקע `primary/10` + טקסט primary + אייקון מעט עבה יותר.  
- אזור התוכן נפתח לרוחב מלא (בלי הגבלת max-w-md).  
- אין bottom nav.  
- כותרות / padding מעט גדולים יותר (`md:px-6 md:py-4`).

### 7.3 מסכים מיוחדים
- טפסים ציבוריים / מבחן / פורטל מדריך: עמודה צרה (`max-w-md` / `max-w-lg`), לעיתים כרטיס ממורכז בדסקטופ עם צל עדין.

## 8. דפוסי מסך נפוצים (Patterns)

1. **רשימת כרטיסים** — כרטיס לכל רשומה, לחיץ, עם שורה ראשית מודגשת + מטא קטנה.  
2. **גריד פעולות מהירות** — 2–3 עמודות של כפתורי אריח (אייקון + כותרת + תיאור קצר).  
3. **טופס ארוך** — סקשנים מעוגלים, שדות מלא־רוחב, כפתור שמירה גדול בתחתית.  
4. **בחירה מתוך רשימה בדיאלוג** — חיפוש למעלה + רשימה גלילה + סימון / בחירה.  
5. **סינון + חיפוש** בשורה עליונה מתחת ל־PageHeader.  
6. **מצב ריק** — קופסה מקווקוות + משפט קצר.

---

## 9. תנועה ואינטראקציה

- מעברים קצרים (~100–200ms).  
- פתיחת מודאל: fade + zoom קל.  
- לחיצה בנייד: scale קל למטה (feedback).  
- אין אפקטי glow / ניאון / גרדיאנטים סגולים כבדים בממשק התפעולי.  
- Backdrop של מודאלים: כהה עדין + blur קל — לא מסך שחור מלא.

---

## 10. נגישות ושימושיות (לשמור בעיצוב החדש)

- אזורי לחיצה גדולים מספיק לאצבע (במיוחד ב־bottom nav).  
- Focus visible עם טבעת כחולה.  
- טקסט על primary תמיד לבן / contrast גבוה.  
- מצב disabled: opacity ~50%.  
- אל תסמכו על צבע בלבד לסטטוסים — שלבו טקסט/אייקון.

---

## 11. מה לשכפל באפליקציה החדשה (צ׳קליסט למעצב)

1. גופן **Assistant**, ממשק **RTL עברית**.  
2. ערכת צבעים מבוססת tokens (רקע בהיר + primary כחול + semantic success/warning/destructive).  
3. רדיוס בסיס ~12px; כרטיסים **rounded-2xl**.  
4. אייקונים **Lucide** outline.  
5. נייד: bottom nav + bottom sheet ל«עוד»; דסקטופ: sidebar ימני.  
6. דיאלוגים ממורכזים, מעוגלים, blur ברקע, כפתורים רחבים בנייד.  
7. Toast עליון־מרכזי.  
8. כותרת דביקה עם blur.  
9. אסתטיקה: נקייה, שטוחה־למעשה, בלי דארק־מוד כברירת מחדל.  
10. טכנולוגית מומלצת לשכפול קרוב: Tailwind + shadcn (base-nova) + Base UI + Lucide + Sonner.

## 12. הערות למסירת Figma / Design System

מומלץ לבנות ב־Figma:

- **Foundations:** Colors (tokens), Typography (Assistant scale), Radius, Spacing (4/8/12/16/24).  
- **Components:** Button, Input, Card, Dialog, Sheet, Toast, Nav (mobile + desktop), PageHeader, Badge, Checkbox.  
- **Templates:** List screen, Form screen, Quick-actions grid, Empty state.  
- **Breakpoints:** Mobile (~390px width frame), Desktop (sidebar 256 + content).

אם צריך ייחוס ויזואלי מהיר: צלמו מסך דשבורד + רשימת לידים + דיאלוג + תפריט «עוד» בנייד, וסיידבר בדסקטופ — אלה ארבעת ה«אנקרים» של המערכת.
